# aymm2
Are You My Mother is a mobile application currently built on base 44 (Repo: nateadmin/aymm), which we are currently rebuilding in our custom environment on a Contabo server. (IP: 185.198.27.3)
 the core premise is a multi-faceted social network whereby children who have been abandoned by their parents could find new parents to connect to, and parents who don't have children could connect with children looking for a parental figure. 
 The new app on the custom environment is going to follow a predetermined and fully designed UI and UX. We only reference the base 44 version for insight into development logic.
